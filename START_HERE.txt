GITHUB UPLOAD STEPS
1. Upload this ZIP to the root of Daily-tracker-v7.
2. Delete the older 02-Daily-Routine-Tracker-3.2-Premium-Editorial-Flow.zip from the repository root.
3. Keep .github/workflows/done.yml unchanged.
4. Open GitHub Actions and check the newest Build Daily Routine Tracker APK run after the old ZIP is deleted.

The workflow selects a ZIP from the repository. Make sure the 3.3 ZIP is the only root-level project ZIP before relying on the APK build.
